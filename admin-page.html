Publishing

Uploads are processed through the secure server API and deployed to Vercel when you run npx vercel --prod. Original photos are preserved; new photos are added to the album.

The manager connects to the secure API endpoint. On localhost, authentication is automatic. On Vercel, a secret token is required.
