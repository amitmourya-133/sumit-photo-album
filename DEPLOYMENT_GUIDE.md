# Step 3: Deployment & QR Code Guide

## Option A: Deploy to Netlify (2 minutes)

### 1. Prepare your project folder
Ensure these files exist in `D:\photo pp`:
- `index.html`
- `css/style.css`
- `js/slideshow.js`
- `photos/` (folder with WebP images)
- `photos.json` (generated by resize.js)
- `music.mp3` (your background song)
- `resize.js` (optional — for re-processing images)

### 2. Drag & drop to Netlify
1. Go to <https://netlify.com> and log in (or create free account)
2. Click **New site → Drag and drop**
3. Drag the entire `D:\photo pp` folder onto the browser window
4. Wait ~30 seconds — Netlify will detect it's a static site
5. Your site will be live at a random subdomain like `https://random-name.netlify.app`

### 3. (Optional) Custom domain
In Netlify dashboard → Domain settings → Add custom domain.

---

## Option B: Deploy to Vercel (2 minutes)

1. Go to <https://vercel.com> and log in (or create free account)
2. Click **New Project → Import Git Repository**
3. If you have Git: push your folder to GitHub, then import
4. Or: click **Upload** and drag `D:\photo pp` folder
5. Vercel will auto-detect React/Next.js — click **Override** → **Set to "Static HTML"**
6. Click **Deploy**

Your site is live instantly at a Vercel subdomain.

## Free QR Code Generation & Testing

### 1. Generate free QR code
- Go to <https://qrcode-generator.com> or <://qr-code-generator.com>
- Paste your Netlify/Vercel URL (e.g., `https://random-name.netlify.app`)
- Click **Download** → choose **PNG** or **SVG**
- Name it `album-qr.png`

### 2. Test on mobile
1. On your phone, open the Camera app (or Google Lens)
2. Scan the QR code
3. The album page should load — verify:
   - First photo displays
   - Tap anywhere → advances to next photo
   - After 5 seconds → auto-changes (if no tap)
   - Swipe left/right → navigates
   - Music toggle works
   - Counter shows correct number (1/1000, 2/1000, etc.)

### 3. Pro tips
- **Test in incognito** to avoid cached data
- **Share the QR** via WhatsApp/Telegram to friends for real-world testing
- If photos don't load, check that `photos.json` paths are correct (they should start with `/photos/`)
